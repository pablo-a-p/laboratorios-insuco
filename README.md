# Proyecto: Laboratorios INSUCO Valparaíso

## Descripción del Sitio
Este sitio web es completamente **responsivo**, adaptándose a cualquier tamaño de pantalla mediante el uso de CSS (Flexbox y Media Queries) y la etiqueta meta viewport. Su objetivo principal es informar a la comunidad estudiantil sobre la disponibilidad de los laboratorios del liceo, detallando cuándo están ocupados o desocupados.

**Dominio del sitio:** [https://proyectopabloaraos-cl.netlify.app/]

## Documentación del Código y Estructura
El proyecto está desarrollado en HTML y CSS puro, estructurado en las siguientes páginas:

* **index.html**: Página de inicio con la bienvenida, introducción al proyecto y menú de navegación principal.
* **sobremi.html**: Perfil del desarrollador (Pablo Araos Pereira) detallando información académica y objetivos profesionales en el área de programación.
* **laboratorios.html**: Panel central que funciona como menú para acceder a la información específica de cada laboratorio.
* **Laboratorios individuales (1 al 5)**: Páginas que detallan el estado y equipamiento de cada sala. **Nota técnica importante: El Laboratorio 3 es el único que cuenta con el sistema operativo Ubuntu.**
* **contacto.html**: Página que incluye la información de ubicación del liceo y un formulario interactivo para consultas.
